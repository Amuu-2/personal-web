=== 个人主页项目 - 操作备忘 ===

【线上地址】
https://amuu-2.github.io/personal-web/

【部署方式】
推送到 master 后，手动执行：
  npm run build
  git checkout gh-pages
  cp -r dist/* .
  git add -A && git commit -m "部署" && git push origin gh-pages
  git checkout master

【退回存档】
在项目目录下打开 CMD，输入：
  git checkout .
  git clean -fd

【查看存档记录】
  git log --oneline
